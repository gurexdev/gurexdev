## José Gutiérrez

Desarrollador de software en Manta, Ecuador. Desde 2022 programo sistemas que usan negocios todos los días: el sistema de recetas del Consultorio Médico Adulam, BARBUS para barberías y el CRM y la tienda web de Tahor Clean.

Me encargo del sistema completo. Diseño la base de datos en PostgreSQL, defino qué puede ver cada usuario y cada empresa con Row Level Security, configuro el servidor con HTTPS y firewall, programo las copias de respaldo y busco vulnerabilidades antes de entregar. Fuera de los proyectos de clientes escribo herramientas de seguridad en Python y estudio redes y administración de Linux.

Busco un puesto como desarrollador de software, remoto o en Ecuador.
